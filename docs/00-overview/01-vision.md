# ۱. چشم‌انداز محصول

## ۱.۱ مسئله

بازار طلای آب‌شده امروز در ایران با ابزارهای زیر اداره می‌شود:

- تماس تلفنی و پیام‌رسان برای اعلام قیمت و توافق معامله
- دفتر دستی یا اکسل برای ثبت طرف‌حساب
- نرم‌افزار حسابداری محلی (تک‌کاربره، جزیره‌ای) در هر مغازه
- تسویه ریالی از طریق کارت‌به‌کارت/پایا و تسویه طلایی از طریق تحویل فیزیکی
- اعتماد شخصی به‌جای ساختار اعتبارسنجی

نتیجهٔ این وضعیت:

| مشکل | اثر |
|---|---|
| **عدم شفافیت قیمت** | هر معامله‌گر قیمت متفاوتی می‌شنود؛ اسپرد پنهان بالا |
| **ریسک نکول (Counterparty Risk)** | طلا تحویل شده ولی وجه نرسیده، یا برعکس |
| **خطای انسانی در محاسبه عیار** | اختلاف در وزن خالص، منجر به دعوا |
| **دوباره‌کاری ثبت** | یک معامله در دفتر خودت، دفتر طرف مقابل و نرم‌افزار جداگانه ثبت می‌شود |
| **عدم ردیابی زنجیره طلا** | مشخص نیست یک شمش از کدام ذوب و کدام ری‌گیری آمده |
| **حمل‌ونقل غیرضروری** | طلا فقط برای انتقال مالکیت جابه‌جا می‌شود |
| **عدم امکان حسابرسی** | تاریخچه قابل بازسازی نیست |

## ۱.۲ ارزش پیشنهادی

`Gold B2B` این مشکلات را با چهار حرکت اصلی حل می‌کند:

### الف) بازار شفاف (Price Discovery)
یک دفتر سفارش (Order Book) و سازوکار RFQ که در آن قیمت واقعی خرید و فروش
میان اعضای احراز هویت‌شده صنف قابل مشاهده است.

### ب) دفتر کل دوگانه (Dual Ledger)
هر عضو دو دفتر کل `append-only` دارد: **دفتر طلا** (به گرم خالص) و
**دفتر ریال**. تمام معاملات، تسویه‌ها، کارمزدها و اصلاحات به‌صورت سطرهای
غیرقابل‌حذف در این دو دفتر ثبت می‌شوند. مانده همیشه از روی دفتر بازسازی‌پذیر است.

### ج) جدایی مالکیت از حضور فیزیکی
با ثبت `GoldLot` در خزانه و تفکیک `Owner` از `Custodian`، انتقال مالکیت
بدون جابه‌جایی فیزیکی ممکن می‌شود. این تنها راه کاهش جدی هزینه، ریسک حمل و
زمان تسویه در بازار عمده است.

### د) تسویه ساختاریافته + تهاتر (Netting)
موتور تسویه مستقل، وضعیت‌های میانی (قفل طلا، انتظار پرداخت، انتقال) را
مدیریت می‌کند و در پایان دوره می‌تواند بدهی‌های متقابل را تهاتر کند تا
حجم عملیات جابه‌جایی به‌شدت کاهش یابد.

## ۱.۳ آنچه این محصول **نیست**

| نیست | چرا |
|---|---|
| اپلیکیشن خرید طلای آب‌شده برای عموم مردم | بازار خرده کاملاً متفاوت است: KYC سبک، مبالغ کوچک، الزامات حفاظت از مصرف‌کننده، مقررات متفاوت |
| صرافی رمزارز/توکن طلا | هیچ توکن قابل انتقال خارج از سامانه صادر نمی‌شود |
| نرم‌افزار حسابداری تک‌مغازه | حسابداری یک **زیرسیستم** است، نه محصول |
| کیف پول طلا برای سرمایه‌گذاری خرد | خارج از دامنه و پرریسک از نظر مقرراتی |

## ۱.۴ معیارهای موفقیت

| شاخص | هدف سال اول |
|---|---|
| اعضای فعال احراز هویت‌شده | ۲۵۰ واحد صنفی |
| حجم ماهانه معامله | ۵۰۰ کیلوگرم طلای خالص |
| نرخ تسویه به‌موقع | > ۹۹٪ |
| نرخ اختلاف (Dispute Rate) | < ۰٫۲٪ |
| میانگین زمان تسویه | < ۴ ساعت کاری |
| نسبت معاملات تهاترشده | > ۳۰٪ حجم |
| اتصال API به نرم‌افزارهای صنفی | ≥ ۳ نرم‌افزار پرکاربرد |

## ۱.۵ اصل راهنما

> **«هیچ عددی در این سیستم بدون منشأ قابل ردیابی وجود ندارد.»**

اگر مانده طلای یک عضو ۱٬۲۴۷٫۳۲ گرم است، باید بتوان دقیقاً نشان داد این عدد
از جمع کدام سطرهای دفتر، ناشی از کدام معاملات، کدام lotها، کدام گواهی‌های
ری‌گیری و کدام تسویه‌ها ساخته شده است.
