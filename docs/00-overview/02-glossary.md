# ۲. واژه‌نامه (Glossary)

این واژه‌نامه **قرارداد زبانی پروژه** است. نام موجودیت‌ها در کد، نام جداول در
دیتابیس و متن رابط کاربری همگی باید از همین واژگان استفاده کنند.

---

## ۲.۱ اصطلاحات بازار طلا

| فارسی | انگلیسی / کد | تعریف دقیق |
|---|---|---|
| طلای آب‌شده | Melted Gold / Refined Bar | طلای ذوب‌شده به شکل شمش یا قطعه، بدون اجرت ساخت، که واحد معاملهٔ عمده در بازار است |
| عیار | `purity` | خلوص طلا بر حسب هزارم (ppt). مثال: `750` یعنی ۷۵٪ خالص. در سیستم همیشه عدد صحیح ۰ تا ۱۰۰۰ |
| وزن ناخالص | `gross_weight` | وزن فیزیکی قطعه بر حسب گرم |
| وزن خالص | `fine_weight` | `gross_weight × purity / 1000` — طلای ۱۰۰٪ معادل |
| ری‌گیری | Assay | فرآیند آزمایشگاهی تعیین عیار دقیق یک قطعه |
| انگ | Hallmark / Assay Code | کد حک‌شده روی قطعه که به گواهی ری‌گیری اشاره می‌کند |
| آبشده‌فروش | Refiner / Melter | واحدی که طلا را ذوب و به شمش تبدیل می‌کند |
| بنکدار | Wholesaler | عمده‌فروش با حجم بالا؛ عملاً بازارساز |
| مظنه | Mesghal Quote | قیمت مرجع بازار داخلی برای یک مثقال طلای ۱۷ عیار |
| مثقال | Mesghal | واحد سنتی وزن = `4.6083` گرم |
| اجرت | Making Charge | خارج از دامنه این سیستم (مربوط به طلای ساخته‌شده) |
| حباب | Premium | اختلاف قیمت بازار داخلی با ارزش ذاتی مبتنی بر اونس جهانی و نرخ ارز |
| اونس | Troy Ounce | `31.1034768` گرم |

## ۲.۲ اصطلاحات معاملاتی

| اصطلاح | تعریف |
|---|---|
| **Order** | قصد معامله ثبت‌شده در سامانه (خرید یا فروش) که هنوز اجرا نشده |
| **Trade** | یک معاملهٔ منعقدشده بین دو طرف مشخص |
| **Order Book** | دفتر سفارش؛ فهرست مرتب سفارش‌های خرید (Bid) و فروش (Ask) |
| **Matching Engine** | موتوری که سفارش‌های سازگار را به معامله تبدیل می‌کند |
| **OTC** | Over-The-Counter؛ معاملهٔ مستقیم و دوطرفه خارج از دفتر سفارش |
| **RFQ** | Request For Quote؛ درخواست قیمت از چند فروشندهٔ منتخب برای حجم بزرگ |
| **Bid / Ask** | بهترین قیمت خرید / بهترین قیمت فروش |
| **Spread** | `Ask − Bid` |
| **Market Order** | سفارش با بهترین قیمت موجود |
| **Limit Order** | سفارش با سقف/کف قیمت مشخص |
| **Fill** | اجرای (کامل یا جزئی) یک سفارش |
| **Partial Fill** | اجرای بخشی از حجم سفارش |
| **Self-Trade** | معاملهٔ عضو با خودش — سیستم باید مانع آن شود |

## ۲.۳ اصطلاحات مالی و تسویه

| اصطلاح | تعریف |
|---|---|
| **Ledger** | دفتر کل `append-only`؛ منبع حقیقت مانده |
| **Ledger Entry** | یک سطر غیرقابل‌حذف در دفتر کل |
| **Gold Ledger** | دفتر کل طلا، واحد: **میلی‌گرم طلای خالص** (`BIGINT`) |
| **Rial Ledger** | دفتر کل ریالی، واحد: **ریال** (`BIGINT`) |
| **Available Balance** | مانده قابل استفاده |
| **Reserved / Blocked** | مانده قفل‌شده بابت سفارش باز یا تسویه در جریان |
| **Clearing** | تعیین اینکه چه کسی به چه کسی چه چیزی بدهکار است |
| **Settlement** | اجرای واقعی انتقال طلا و وجه |
| **Netting** | تهاتر تعهدات متقابل و کاهش آن‌ها به یک مانده خالص |
| **Escrow** | نگهداری امانی دارایی توسط سامانه تا تکمیل تسویه |
| **Reversal** | رکورد معکوس برای خنثی کردن یک ثبت اشتباه (به‌جای حذف) |
| **T+0 / T+1** | تسویه در همان روز / روز کاری بعد |
| **DvP** | Delivery versus Payment؛ تحویل همزمان طلا و وجه |

## ۲.۴ اصطلاحات فیزیکی و خزانه

| اصطلاح | تعریف |
|---|---|
| **Gold Lot** | کوچک‌ترین واحد قابل ردیابی طلای فیزیکی با شناسه یکتا |
| **Custody** | نگهداری فیزیکی؛ مستقل از مالکیت |
| **Custodian** | نگهدارندهٔ فیزیکی (خزانه، آزمایشگاه، خود عضو) |
| **Vault** | خزانه؛ محل فیزیکی نگهداری |
| **Allocated Gold** | طلای تخصیص‌یافته؛ lot مشخص متعلق به مالک مشخص |
| **Unallocated Gold** | طلای غیرتخصیص‌یافته؛ فقط ادعای وزنی، بدون lot مشخص |
| **Split** | تفکیک یک lot به چند lot کوچک‌تر |
| **Merge** | ادغام چند lot در یک lot |
| **Genealogy** | شجره‌نامه lot؛ گراف والد/فرزند lotها در طول ذوب و تفکیک |
| **Assay Certificate** | گواهی ری‌گیری صادرشده توسط آزمایشگاه |
| **Vault IN / OUT** | ورود / خروج فیزیکی طلا از خزانه |

## ۲.۵ اصطلاحات هویت و انطباق

| اصطلاح | تعریف |
|---|---|
| **Member** | عضو صنفی (حقیقی یا حقوقی) — واحد مالکیت دارایی |
| **Organization** | همان Member در سطح داده؛ سازمان صنفی |
| **User** | کاربر انسانی که به سیستم لاگین می‌کند؛ متعلق به یک Organization |
| **Representative** | نمایندهٔ مجاز عضو برای انجام معامله |
| **KYC** | Know Your Customer؛ فرآیند احراز هویت عضو |
| **AML** | Anti-Money Laundering؛ مبارزه با پولشویی |
| **Trading Limit** | سقف حجم معامله عضو |
| **Credit Score** | امتیاز اعتباری داخلی عضو |
| **Flag** | نشانه‌گذاری رفتار مشکوک برای بررسی |
| **Dispute** | اختلاف ثبت‌شده روی یک معامله |
| **Audit Log** | ثبت غیرقابل‌تغییر تمام اقدامات حساس |

## ۲.۶ قرارداد واحدها (بسیار مهم)

> ⚠️ **هرگز از `FLOAT` یا `DOUBLE` برای مقادیر مالی استفاده نکنید.**

| کمیت | واحد ذخیره | نوع MySQL | مثال |
|---|---|---|---|
| وزن ناخالص | میلی‌گرم | `BIGINT UNSIGNED` | `127.42 g` → `127420` |
| وزن خالص | میلی‌گرم | `BIGINT UNSIGNED` | `95.565 g` → `95565` |
| عیار | هزارم (ppt) | `SMALLINT UNSIGNED` | `750` |
| مبلغ ریالی | ریال | `BIGINT` (علامت‌دار برای دفتر) | `185_400_000` |
| قیمت هر گرم خالص | ریال | `BIGINT UNSIGNED` | `78_500_000` |
| درصد (کارمزد) | صدم‌هزارم (basis-point ×10) | `INT UNSIGNED` | `0.15%` → `1500` |

**نمایش در UI** با تبدیل در لایهٔ presentation انجام می‌شود، نه در دیتابیس.
