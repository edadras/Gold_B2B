### قواعد UX ثبت سفارش

</div>

```
۱) محاسبه زنده — هر تغییر مقدار یا قیمت، خلاصه را به‌روز کند
۲) اعتبارسنجی محلی پیش از ارسال:
   · حداقل/حداکثر مقدار
   · مضرب گام قیمتی
   · موجودی کافی
   · انحراف قیمت از مرجع
۳) هشدار صریح اگر قیمت > ۵٪ از بازار فاصله دارد
۴) دکمه ثبت غیرفعال تا اعتبارسنجی کامل
۵) تأیید نهایی با bottom sheet + بیومتریک (اگر مبلغ بالا)
۶) پس از ثبت: بازخورد فوری، حتی اگر هنوز اجرا نشده
۷) اگر بازار بسته است: فرم غیرفعال + پیام صریح
```

```dart
// همیشه از ویجت مشترک استفاده شود، نه Text خام

class WeightDisplay extends StatelessWidget {
  final FineWeight weight;
  final WeightStyle style;
  final bool showUnit;

  const WeightDisplay(this.weight, {
    this.style = WeightStyle.normal,
    this.showUnit = true,
  });

  @override
  Widget build(BuildContext context) {
    return Text(
      showUnit ? weight.displayGramsWithUnit : weight.displayGrams,
      style: _resolveStyle(context),
      textDirection: TextDirection.ltr,   // ◄── اعداد همیشه LTR
    );
  }
}
```

> وگرنه ترتیب ارقام و جداکننده‌ها به هم می‌ریزد.
